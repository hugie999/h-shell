! commands

thease are commands for shell funtions

commands:

!                       - enable multiline input (ends when another `!` command is entered)
!NOECHO                 - disables echoing file commands
!YESECHO                - re-enables echoing file commands
!SET (var) (value)      - sets a variable to a value
!GET (var)              - prints a variable
!GETENV (env variable)  - prints an envirenment variable
!RUNIF (var) (command)  - runs a command only if the variable is 0
!SETTO (command)        - sets a var to the return code of program
!SETSTRICT              - sets file to strict mode (file will stop if a command exits without code 0)
!SETPOLITE              - unsets the file from strict mode
!CHECK (SUM)            - checksums the file (note only applied to lines AFTER this command)
!TAG (tagname)          - creates a tag (for use with goto)
!TAG (tagname)          - removes a tag
!GOTO (tagname)         - goes to a tag
!JUMP (tagname) (lines) - searches forward by (lines) until the tag (tagname) is found, this command only goes forwards
!MATH (operation)       - preforms the specified operation and prints the output (this can also contain variables)

extras:

special vars:
    FILE         - the current file
    STRICT       - see !SETSTRICT
    SPECIALCHARS - sets wether special characters will be replaced 

substituion:
    `COMMAND` -> (the command's STDOUT)
    $COMMAND$ -> (the command's return code)
    (note subsitutions cannot be nested)
